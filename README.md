# أذكار | لوحة إدارة وتوثيق متون الأذكار والأحاديث النبوية
### Serene Adhkar & Hadith Sanctuary Manager

تطبيق ويب حديث ومتكامل لإدارة الأوراد والأذكار النبوية الشريفة، وتصنيفها، وتوثيق أحاديثها المسندة وتخريجها مع بيان الكتب والأرقام ودرجات الصحة، مستضاف بالكامل على **GitHub Pages**.

🔗 **رابط التطبيق المباشر (Live GitHub Pages):**  
[https://moamenmoheb.github.io/adhkar-manager/](https://moamenmoheb.github.io/adhkar-manager/)

## 🌟 أبرز المميزات

1. **إدارة متون الأذكار (Dhikr Management):**
   - إضافة وحفظ الأذكار بالتشكيل العربي الدقيق.
   - تحديد عدد التكرار الشرعي (مع عداد تسبيح تفاعلي فوري).
   - توضيح فضل الذكر وثوابه وأثره.
   - التحكم في حالة النشر (نشط / مسوّدة).

2. **أنواع وتصنيفات الأذكار (Zekr Categories):**
   - تصنيف الأذكار بحسب الأوقات والأبواب (أذكار الصباح والمساء، أذكار الصلاة، أذكار النوم، أدعية قرآنية، أدعية السفر، أذكار عامة).
   - إمكانية إضافة تصنيفات وأنواع جديدة في أي وقت.

3. **التوثيق النبوي الشريف والتخريج (Hadith & Source Documentation):**
   - إمكانية ربط كل ذكر بحديث نبوي مسند أو عدة أحاديث.
   - تحديد مصدر الحديث (صحيح البخاري، صحيح مسلم، سنن أبي داود، سنن الترمذي، سنن النسائي، سنن ابن ماجه، مسند أحمد، إلخ).
   - إدخال رقم الحديث في الطبعات المعتمدة.
   - بيان موضع الحديث (الكتاب والباب).
   - بيان درجة صحة الحديث (صحيح، حسن، متفق عليه، إلخ).

4. **لوحة تحكم تفاعلية (Spiritual Dashboard):**
   - إحصائيات حية عن إجمالي الأذكار، نسبة الأذكار الموثقة بالأحاديث، وعدد التصنيفات.
   - شريط توزيع الأذكار ونسبتها المئوية حسب كل تصنيف.
   - سجل بأحدث الأذكار المضافة.

5. **البحث الحي والتصفية السريعة (Live Search & Filter):**
   - بحث فوري وشامل في متن الذكر، فضله، اسم الذكر الإداري، متن الحديث، أو مصدره ورقمه.
   - تصفية سريعة بالضغط على أي تصنيف.
   - فلتر خاص لعرض الأذكار الموثقة بالحديث فقط.

6. **النسخ الاحتياطي وإدارة البيانات (JSON Backup & Restore):**
   - تصدير كامل قاعدة البيانات بضغطة زر كملف `JSON`.
   - استيراد واسترجاع البيانات بسهولة.
   - حفظ تلقائي فوري في المتصفح (`localStorage`).

## 🎨 الهوية البصرية والتصميم

- مستوحى من نظام تصميم **Serene Dhikr Sanctuary**.
- ألوان مستوحاة من الهوية النبوية والسكينة (الأخضر النبوي `#003527`، الفيروزي `#006a61`، ودرجات السطح الهادئة).
- خطوط عربية أصيلة:
  - `IBM Plex Sans Arabic` للعناوين والأرقام.
  - `Noto Naskh Arabic` للمتون الشريفة بالتشكيل الكامل.

## 🚀 التشغيل المحلي (Local Running)

التطبيق خفيف ولا يحتاج إلى تثبيت أي حزم (Zero-Dependency):
```bash
# قم بفتح index.html مباشرة في أي متصفح
open index.html
# أو تشغيل خادم محلي:
python3 -m http.server 8000
```
ثم افتح `http://localhost:8000`.
